===========================
Carbonio App Authentication
===========================

You can generate authentication credentials in Carbonio webmail to sign in to Carbonio mobile applications, such as Mail, Chats.


Generate Authentication Credentials
====================================

1. Sign in to **Carbonio webmail**.
2. Go to **Settings > AUTH > Mobile Apps**.

.. image:: /img/mobile-apps.png
              :class: bordered-image
              :align: center
              :width: 100%

3. Click **NEW AUTHENTICATION +**.
4. Enter a description for the authentication credential to identify it.
5. Click **CREATE PASSWORD**. A QR code is generated.
6. Open the Carbonio mobile application on your device and scan the QR code to authenticate the application. Alternatively, click **COPY QR CODE** to copy the text version of the QR code. Paste this text into the mobile application manually.

.. image:: /img/new-authentication.png
              :class: bordered-image
              :align: center
              :width: 100%

7. Click **DONE** to complete the process.


.. note::

   Signing in to one Carbonio mobile application also grants access to the other application. If access to the other application is not granted automatically, generate a separate authentication credential specifically for that application.
